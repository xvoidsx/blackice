# Blackice Privacy Policy

**Effective date:** September 22, 2026

Blackice is built by the xvoidsx collective. This policy is short because
there is almost nothing to say.

## Data collection

Blackice collects no personal data. It has no accounts, no analytics, no
telemetry, and makes no network requests of its own. All content blocking
happens locally on your device using filter lists stored on your device.

## Filter list updates

Like uBlock Origin Lite, from which Blackice is forked, the extension
periodically fetches filter-list updates from public filter-list sources
over HTTPS. These requests contain no identifying information beyond what
is inherent to any HTTPS request (such as your IP address, visible to the
list host as with any web request).

## Permissions

Blackice requests broad host permissions because content blocking
requires seeing web requests to block them. Blocked or allowed requests
are never transmitted anywhere.

## Changes

If this policy ever changes, the new version will be posted at this URL
with a new effective date.
